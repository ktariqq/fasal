# References

## Data and documentation

- NASA-ISRO NISAR mission, L-band SAR, and its Level 2 GCOV product, distributed by the ASF DAAC: https://www.earthdata.nasa.gov/data/platforms/space-based-platforms/nisar
- ASF Data Search (Vertex): https://search.asf.alaska.edu
- NISAR Data User Guide (ASF): https://nisar-docs.asf.alaska.edu
- Data statement: Central Punjab uses real NISAR GCOV acquisitions (track 135, descending; see the acquisition dates in the app). Larkana and Tharparkar use ILLUSTRATIVE DEMO DATA (synthetic, generated by `pipeline/07_make_demo_data.py`) unless a site's `series.json` says `"data_mode": "real"`.
- Field polygons for real sites are derived from the radar time series itself (`pipeline/04_derive_fields.py`) and are homogeneous radar patches, not surveyed field boundaries.
- Basemap: Sentinel-2 cloudless 2020 by EOX IT Services GmbH, contains modified Copernicus Sentinel data (CC BY-NC-SA 4.0): https://s2maps.eu. Verify the licence before any commercial reuse.
- Country outlines: `world-atlas` npm package (Natural Earth-derived, public domain): https://github.com/topojson/world-atlas
